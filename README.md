# Chord-nator UI

A modern chord progression and music composition tool built with React Native and Expo.

## Features

- Interactive chord composition
- Real-time audio playback using Tone.js
- Chord progression management
- Cross-platform support (iOS, Android, Web)
- Modern, intuitive UI
- Saved chord and progression functionality

## Tech Stack

- React Native / Expo
- TypeScript
- Tone.js for audio
- Zustand for state management
- NativeWind for styling

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Expo CLI

### Installation

1. Clone the repository:
```bash
git clone https://github.com/sunlandmusic/CHORD-INATERUI.git
cd CHORD-INATERUI
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Start the development server:
```bash
npm start
# or
yarn start
```

### Running on Different Platforms

- Web: Press 'w' in the terminal or run `npm run start-web`
- iOS: Press 'i' in the terminal (requires macOS and Xcode)
- Android: Press 'a' in the terminal (requires Android Studio)

## Project Structure

- `/app` - Main application screens and navigation
- `/components` - Reusable UI components
- `/utils` - Helper functions and utilities
- `/stores` - State management
- `/types` - TypeScript type definitions
- `/assets` - Images, fonts, and other static assets
