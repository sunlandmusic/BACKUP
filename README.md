# ChordCraft

ChordCraft is a modern, intuitive music application for chord progression creation and exploration.

## Documentation

All documentation can be found in the `docs/` directory. Here are quick links to specific components:

### Components
- [Edit Modal](docs/edit-modal.md) - Documentation for the chord editing modal component

### Getting Started
1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npx expo start
```

3. Use Expo Go on your mobile device or press 'w' for web version

## Project Structure
```
CHORDCOMPOSE/
├── app/            # Main application screens
├── components/     # Reusable React components
├── constants/      # Application constants
├── docs/          # Documentation
├── types/         # TypeScript type definitions
└── utils/         # Utility functions
```
